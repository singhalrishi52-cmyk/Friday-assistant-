FRIDAY ANDROID STARTER V0.1

Features: futuristic HUD, demo chat, browser-supported voice input, text-to-speech, local notes, simple task list, basic offline cache.

यह अभी complete AI या full phone automation नहीं है। Android के दूसरे apps/files को बिना permission control नहीं करता।

Install:
1. ZIP extract करें।
2. GitHub पर public repository बनाएं।
3. इस folder की सभी files और icons folder upload करें। index.html repository root में हो।
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. HTTPS link Chrome में खोलें > menu > Install app / Add to Home screen.

यह APK नहीं है। Native APK के लिए Android build environment चाहिए। Public files में password/API key न रखें।
